# HTML5 Semantic Structure & Accessibility Portfolio Website

## Project Overview

This project is a multi-page personal portfolio website developed using modern Semantic HTML5 elements and accessibility best practices. The website follows WCAG accessibility guidelines and is designed to provide a user-friendly experience for all users, including those using assistive technologies.

## Features

* Semantic HTML5 structure using:

  * `<header>`
  * `<nav>`
  * `<main>`
  * `<section>`
  * `<article>`
  * `<footer>`
* ARIA labels and landmarks for improved screen reader support
* Keyboard-accessible navigation
* Accessible contact form with proper labels
* SEO-friendly meta tags
* Responsive design using CSS
* Skip navigation link for accessibility
* Mobile-friendly layout

## Website Pages

### Home (index.html)

* Introduction and welcome section
* Skills overview

### About (about.html)

* Personal profile
* Educational background

### Projects (projects.html)

* Showcase of featured projects
* Project descriptions

### Contact (contact.html)

* Accessible contact form
* User-friendly input fields

1. Download or clone the repository.

3. Open `index.html` using Live Server.
4. Navigate through the website pages using the menu.
